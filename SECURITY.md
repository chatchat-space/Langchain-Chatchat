# Security Policy

## Supported Versions

Security updates are provided for the latest release on the default branch (`master`). Please upgrade to the newest version when possible.

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

If you believe you have found a security issue in Langchain-Chatchat, report it privately so maintainers can investigate and remediate before public disclosure.

### Preferred channels

1. **GitHub Private Vulnerability Reporting** (when enabled): repository **Security** tab → **Report a vulnerability**.
2. **Project Telegram group**: [langchain-chatchat Telegram](https://t.me/+RjliQ3jnJ1YyN2E9) — ask for a private channel with maintainers; do not paste exploit details in public chat.
3. If you already have a maintainer contact from prior coordination, use that private email instead of filing a public issue.

Please include:

- Description of the issue and impact
- Steps to reproduce or a proof of concept
- Affected version(s) / commit and environment details
- Suggested remediation if known

### What to expect

- Maintainers will acknowledge receipt when possible and coordinate disclosure timing.
- Please allow a reasonable window for a fix and release before public disclosure.

Thank you for helping keep Langchain-Chatchat and its users safe.
